Styling notes

Everything the form needs for a decent look on any template is a setting on the Appearance tab. The snippets here are for the rest: the cases where there is no setting, because a setting for each of them would turn a contact form into a form builder.

Your selector

Every snippet begins with YOUR-FORM. Replace it with the selector of your own form, which is printed right under the Custom CSS box on the Appearance tab, in the shape #mcx-12, where 12 is the id of this module. Paste the snippet into that same box.

Custom CSS is loaded after everything else the module brings, so it wins without !important. It works with any value of Own Styles, and it applies to this form alone: another instance of the module keeps its own.

1. Which Field Markup to choose

You want: the fields and the button to look like the rest of the site.

Setting: Field Markup — Joomla (Bootstrap 5) for Cassiopeia and other Bootstrap templates, UIkit (YOOtheme) for YOOtheme Pro. On any other template try both and keep the one that looks better; No Added Classes leaves the fields exactly as the template drew them.

Check: the send button takes the shape and colour of other buttons on the site.

2. The form does not look the way you expected

Check in this order:

  1. Own Styles — Full draws borders, frame and button; Basic only spaces the fields out; None hands the whole form to the template.
  2. Field Markup — the wrong framework adds classes the template has no rules for.
  3. Reload the page with Ctrl+Shift+R. A stylesheet that has changed is still the old one in the browser otherwise, and you will be looking at the previous version.
  4. Clear the template cache if your template has one of its own.

3. A shadow around the form

You want: the form to stand out as a card.

Setting: the nearest ones are Frame Around the Form and Form Background. A shadow has none, on purpose: with a template class it is one field away, see Wrapper Class and its card or uk-card.

Snippet:

YOUR-FORM {
    box-shadow: 0 2px 14px rgba(0, 0, 0, .15);
    border-radius: 6px;
    padding: 20px;
}

Check: the shadow is there, and the fields are not touching the edge. Drop the padding line if Frame Around the Form or Form Background is already on: they bring their own.

4. The button colour on hover

You want: your own colour under the pointer.

Setting: Button Look — Module Button, and Accent Colour for its normal state. The module darkens that colour on hover by itself, and there is no setting for a second colour.

Snippet:

YOUR-FORM .mcx-submit:hover {
    background-color: #1f4f8f;
    filter: none;
}

Check: point at the button. With Template Button the hover is the template's and this snippet does nothing.

5. Name and E-mail in one row on a wide screen

You want: two short fields side by side, everything else full width.

Setting: none. The module keeps one field per row, which is what works on a phone.

Snippet:

@media (min-width: 640px) {
    YOUR-FORM .mcx-form {
        display: grid;
        grid-template-columns: 1fr 1fr;
        column-gap: 16px;
    }

    YOUR-FORM .mcx-form > * { grid-column: 1 / -1; }

    YOUR-FORM .mcx-field-wrap:has(.mcx-field--name),
    YOUR-FORM .mcx-field-wrap:has(.mcx-field--email) { grid-column: span 1; }
}

Check: widen the window — Name and E-mail share a row, the message box and the button stay full width. Narrow it again: one field per row.

6. The size and colour of the labels

You want: labels quieter, or larger.

Setting: none. Fonts and text sizes belong to the template throughout.

Snippet:

YOUR-FORM .mcx-field .control-label {
    font-size: 15px;
    font-weight: 600;
    color: #555555;
}

Check: every label changes, the consent wording beside the checkbox included.

7. The form on a dark background

You want: the form to sit in a dark section of the page.

Setting: Form Background takes a dark colour, but the text and the fields inside it are the template's.

Snippet:

YOUR-FORM {
    color: #f0f0f0;
    --mcx-error: #ff9a90;
    --mcx-error-bg: #3a2020;
    --mcx-ok: #a5d6a7;
    --mcx-ok-bg: #1f3a24;
}

YOUR-FORM .form-control,
YOUR-FORM .form-select {
    background-color: #2a2c30;
    border-color: #555a61;
    color: #f0f0f0;
}

YOUR-FORM .form-control::placeholder { color: #a6a6a6; }

Check: send the form empty — the refusal has to be readable on the dark background as well, not dark red on dark grey.

8. The colour of error messages

You want: refusals in your own red, or in something softer.

Setting: none — one accent colour covers the button, the focus and the checkbox, and errors are deliberately not tied to it.

Snippet:

YOUR-FORM {
    --mcx-error: #b00020;
    --mcx-error-bg: #fdeaec;
}

Check: send the form with an empty Name. Both the text under the field and the border of the field itself take the new colour.

9. Hiding the stars on required fields

You want: no * after the labels.

Setting: none. Joomla prints the star for every required field.

Snippet:

YOUR-FORM .control-label .star { display: none; }

Check: the stars are gone. The fields stay required, and an empty one is still refused — so say somewhere else which fields have to be filled in.

10. Form Width did nothing, or narrowed too much

You want: the form narrower than the column it stands in.

Setting: Form Width. It narrows the whole module, the title above the form included, by addressing the element your template wraps the module in.

If your template put several modules into that one element, they all narrow together. Set Form Width back to 0 and use this instead, which narrows this form alone:

YOUR-FORM { max-width: 560px; }

Check: the neighbouring modules are their usual width again, and the form is the width you asked for.

When a snippet does nothing

  • Check that YOUR-FORM was replaced by the selector printed under the Custom CSS box — with the # and the right id.
  • Reload with Ctrl+Shift+R.
  • A template rule may be stronger. Write the selector twice, with no space between the two, to outweigh it: #mcx-12#mcx-12 .mcx-submit { … } — an ugly trick, but a legitimate one, and still not !important.
