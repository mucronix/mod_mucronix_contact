Пояснення щодо оформлення

Усе, що потрібно формі для пристойного вигляду на будь-якому шаблоні, задається параметрами на вкладці Оформлення. Шматки CSS нижче — для решти: випадків, на які параметра немає навмисно, інакше форма зворотного зв’язку перетворилася б на конструктор форм.

Ваш селектор

Кожен шматок починається зі слова ВАША-ФОРМА. Замініть його селектором своєї форми — він написаний просто під полем Власний CSS на вкладці «Оформлення» і має вигляд #mcx-12, де 12 — номер цього модуля. Туди ж, у поле «Власний CSS», шматок і вставляється.

«Власний CSS» підключається після всього, що приносить модуль, тому перебиває його без !important. Він працює за будь-якого значення «Власних стилів» і діє лише на цю форму: в іншого екземпляра модуля своє поле і свій селектор.

1. Яку «Розмітку полів» обрати

Що хочете: щоб поля та кнопка мали вигляд решти сайту.

Параметр: «Розмітка полів» — Joomla (Bootstrap 5) для Cassiopeia та інших шаблонів на Bootstrap, UIkit (YOOtheme) для YOOtheme Pro. На решті шаблонів спробуйте обидва і залиште той, що виглядає краще; Без додаткових класів лишає поля точно такими, як їх малює шаблон.

Як перевірити: кнопка надсилання набуває вигляду інших кнопок сайту.

2. Форма виглядає не так, як очікувалося

Перевіряйте по черзі:

  1. «Власні стилі»: Повний малює рамки, обрамлення й кнопку, Базовий — лише відступи між полями, Немає віддає форму шаблону цілком.
  2. «Розмітка полів»: чужий фреймворк додає класи, правил для яких у шаблоні немає.
  3. Оновіть сторінку через Ctrl+Shift+R. Змінений файл стилів інакше лишається в браузері попереднім, і ви дивитесь на стару версію.
  4. Очистіть кеш шаблону, якщо він у вашого шаблону власний.

3. Тінь навколо форми

Що хочете: щоб форма виділялася карткою.

Параметр: найближчі — «Рамка навколо форми» та «Тло форми». Тіні серед параметрів немає навмисно: класом шаблону вона робиться одним полем, див. «Клас обгортки» та його card чи uk-card.

Шматок:

ВАША-ФОРМА {
    box-shadow: 0 2px 14px rgba(0, 0, 0, .15);
    border-radius: 6px;
    padding: 20px;
}

Як перевірити: тінь з’явилася, поля не впираються в край. Рядок padding приберіть, якщо вже увімкнено «Рамку навколо форми» або «Тло форми»: відступ вони дають самі.

4. Колір кнопки при наведенні

Що хочете: свій колір під вказівником миші.

Параметр: «Вигляд кнопки» — Кнопка модуля, а її звичайний колір задає «Колір акценту». При наведенні модуль затемнює цей колір сам, окремого параметра на другий колір немає.

Шматок:

ВАША-ФОРМА .mcx-submit:hover {
    background-color: #1f4f8f;
    filter: none;
}

Як перевірити: наведіть на кнопку. За вигляду «Як у шаблоні» наведення належить шаблону, і цей шматок нічого не дасть.

5. «Ім’я» та «E-mail» в один рядок на широкому екрані

Що хочете: два короткі поля поруч, решта на всю ширину.

Параметр: немає. Модуль тримає по полю в рядку — так форма поводиться на телефоні.

Шматок:

@media (min-width: 640px) {
    ВАША-ФОРМА .mcx-form {
        display: grid;
        grid-template-columns: 1fr 1fr;
        column-gap: 16px;
    }

    ВАША-ФОРМА .mcx-form > * { grid-column: 1 / -1; }

    ВАША-ФОРМА .mcx-field-wrap:has(.mcx-field--name),
    ВАША-ФОРМА .mcx-field-wrap:has(.mcx-field--email) { grid-column: span 1; }
}

Як перевірити: розширте вікно — «Ім’я» та «E-mail» стають в рядок, поле повідомлення й кнопка лишаються на всю ширину. Звузьте назад: знову по полю в рядку.

6. Розмір і колір підписів

Що хочете: підписи тихіші або, навпаки, більші.

Параметр: немає. Шрифти й розміри тексту в усьому модулі належать шаблону.

Шматок:

ВАША-ФОРМА .mcx-field .control-label {
    font-size: 15px;
    font-weight: 600;
    color: #555555;
}

Як перевірити: змінюються всі підписи, зокрема текст згоди поруч із чекбоксом.

7. Форма на темному тлі

Що хочете: поставити форму в темну частину сторінки.

Параметр: «Тло форми» приймає темний колір, але текст і поля всередині лишаються шаблонними.

Шматок:

ВАША-ФОРМА {
    color: #f0f0f0;
    --mcx-error: #ff9a90;
    --mcx-error-bg: #3a2020;
    --mcx-ok: #a5d6a7;
    --mcx-ok-bg: #1f3a24;
}

ВАША-ФОРМА .form-control,
ВАША-ФОРМА .form-select {
    background-color: #2a2c30;
    border-color: #555a61;
    color: #f0f0f0;
}

ВАША-ФОРМА .form-control::placeholder { color: #a6a6a6; }

Як перевірити: надішліть порожню форму — відмова має читатися й на темному, а не виявитися темно-червоним по темно-сірому.

8. Колір повідомлень про помилку

Що хочете: свій червоний або щось м’якше.

Параметр: немає: «Колір акценту» відповідає за кнопку, фокус і чекбокс, а кольори помилок до нього навмисно не прив’язані.

Шматок:

ВАША-ФОРМА {
    --mcx-error: #b00020;
    --mcx-error-bg: #fdeaec;
}

Як перевірити: надішліть форму з порожнім полем «Ім’я». Новий колір візьмуть і текст під полем, і рамка самого поля.

9. Сховати зірочки обов’язкових полів

Що хочете: прибрати * після підписів.

Параметр: немає. Зірочку біля кожного обов’язкового поля друкує Joomla.

Шматок:

ВАША-ФОРМА .control-label .star { display: none; }

Як перевірити: зірочок немає. Поля при цьому лишаються обов’язковими, і порожнє так само відхиляється, — тож скажіть десь іще, що заповнювати обов’язково.

10. «Ширина форми» не подіяла або стиснула зайве

Що хочете: форму вужчу за колонку, в якій вона стоїть.

Параметр: «Ширина форми». Він звужує весь модуль разом із заголовком над формою, звертаючись до того елемента, у який ваш шаблон загортає модуль.

Якщо шаблон поклав у цей елемент кілька модулів, звузяться всі. Поверніть «Ширину форми» в 0 і візьміть шматок — він звужує лише цю форму:

ВАША-ФОРМА { max-width: 560px; }

Як перевірити: сусідні модулі знову звичайної ширини, а форма — тієї, яку ви задали.

Якщо шматок не спрацював

  • Перевірте, що ВАША-ФОРМА замінено селектором із підпису під полем «Власний CSS» — разом із # і з правильним номером.
  • Оновіть сторінку через Ctrl+Shift+R.
  • Правило шаблону може виявитися сильнішим. Напишіть селектор двічі поспіль, без пробілу між ними: #mcx-12#mcx-12 .mcx-submit { … } — прийом негарний, але чесний, і це так само не !important.
