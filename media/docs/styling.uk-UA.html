Пояснення щодо оформлення

Два параметри на вкладці Оформлення вирішують, яку частину вигляду модуль малює сам. Усе інше робиться з шаблону, двома способами: кількома змінними CSS, які читає форма, і заміщенням її макета.

1. Два параметри

  • «Розмітка полів» — Joomla (Bootstrap 5) для Cassiopeia та інших шаблонів на Bootstrap, UIkit (YOOtheme) для YOOtheme Pro, Без додаткових класів лишає поля точно такими, як їх малює шаблон.
  • «Власні стилі» — Повний малює рамку в кожного поля і розставляє поля; Базовий лише розставляє їх і показує помилки; Немає віддає форму шаблону цілком.

Змінивши будь-який із них, оновіть сторінку через Ctrl+Shift+R: інакше в браузері лишається попередній файл стилів.

2. Куди писати правила і ваш селектор

Правила нижче пишуться в CSS вашого шаблону, а не в модуль.

  • Cassiopeia — файл user.css. Поки ви його не створили, його немає: Система → Шаблони сайту → Деталі Cassiopeia → Новий файл, оберіть теку css, у полі «Нове ім'я файлу» впишіть user, у полі «Тип файлу» оберіть css і натисніть Створити. Цей файл Cassiopeia підключає сама.
  • YOOtheme Pro — у Customizer теми, Налаштування → CSS.

Кожен приклад починається зі слова ВАША-ФОРМА. Замініть його на #mcx-12, де 12 — номер цього модуля: стовпець ID у списку модулів сайту. Щоб правило діяло на всі форми зворотного зв’язку одразу, напишіть натомість body .mcx.

3. Змінні, які працюють за «Повного» і «Базового»

ВАША-ФОРМА {
    --mcx-gap: 16px;
    --mcx-label-gap: 4px;
}
  • --mcx-gap — відстань між полями, типово 12px.
  • --mcx-label-gap — відстань між підписом і його полем, 2px.

Повідомлення над формою і під полями мають власні кольори:

ВАША-ФОРМА {
    --mcx-error: #b00020;
    --mcx-error-bg: #fdeaec;
    --mcx-ok: #1f7a3d;
    --mcx-ok-bg: #e9f6ed;
    --mcx-radius: 6px;
}
  • --mcx-error, --mcx-error-bg — помилка: її текст і рамка поля, якого вона стосується, та тло блока повідомлення.
  • --mcx-ok, --mcx-ok-bg — повідомлення після успішного надсилання.
  • --mcx-radius — заокруглення кутів блока повідомлення, 4px.

4. Змінні, які працюють лише за «Повного»

ВАША-ФОРМА {
    --mcx-field-border: #b8bec7;
    --mcx-field-radius: 8px;
    --mcx-form-max: 560px;
    --mcx-accent: #0a7d55;
}
  • --mcx-field-border — колір рамок полів, #dddddd.
  • --mcx-field-radius — заокруглення їхніх кутів, 4px.
  • --mcx-form-max — максимальна ширина форми. Без неї форма займає всю ширину своєї колонки.
  • --mcx-accent — колір поля у фокусі та позначеного чекбокса, #2f6fbf. Обирайте темний: білої позначки на світлому кольорі не видно. За Базового змінна доходить лише до чекбокса згоди, і тільки в шаблоні, який лишає малювання чекбоксів браузеру.

Тлу під формою потрібен ще й відступ усередині, тому вони пишуться разом:

ВАША-ФОРМА {
    --mcx-form-bg: #f6f7f9;
    padding: 16px 20px;
}

За Базового і Немає змінні цього розділу нічого не роблять, окрім одного випадку, названого вище: файл стилів, який їх читає, підключає лише Повний.

5. Заміщення макета

Коли змінної замало, можна замінити саму розмітку — так, як Joomla дозволяє це для будь-якого модуля: Система → Шаблони сайту → ваш шаблон → Створити заміщення → Модулі → mod_mucronix_contact. Joomla скопіює два файли до templates/ваш-шаблон/html/mod_mucronix_contact/, і відтоді сайт бере копії:

  • default.php — форма на сторінці;
  • default_mail.php — тіло листа, який надходить вам.

Щоб лишити початковий вигляд і додати поруч другий, збережіть копію під іншим іменем, наприклад compact.php, і оберіть її в модулі: Додатково → Макет.

Що заміщення default.php мусить зберегти, інакше форма перестане надсилатися: обгортку з класом mcx та ідентифікатором mcx-…, форму з класом mcx-form, блок mcx-message, кнопку mcx-submit, блок mcx-hp з атрибутом hidden, два приховані поля mcx_module_id і mcx_page та токен форми. Після оновлення модуля порівняйте свою копію з новим початковим файлом.

Якщо правило нічого не робить

  • Перевірте, що ВАША-ФОРМА замінено — з решіткою # і правильним номером.
  • Оновіть сторінку через Ctrl+Shift+R і очистіть кеш шаблону, якщо він у нього власний.
  • Перевірте «Власні стилі»: за Немає жоден файл стилів модуля не підключається і жодна змінна не читається.
