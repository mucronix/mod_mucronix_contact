Пояснения по оформлению

Всё, что нужно форме для приличного вида на любом шаблоне, задаётся параметрами на вкладке Оформление. Куски CSS ниже — для остального: случаев, на которые параметра нет намеренно, иначе форма обратной связи превратилась бы в конструктор форм.

Ваш селектор

Каждый кусок начинается со слова ВАША-ФОРМА. Замените его селектором своей формы — он написан прямо под полем Свой CSS на вкладке «Оформление» и выглядит как #mcx-12, где 12 — номер этого модуля. Туда же, в поле «Свой CSS», кусок и вставляется.

«Свой CSS» подключается после всего, что приносит модуль, поэтому перебивает его без !important. Он работает при любом значении «Собственных стилей» и действует только на эту форму: у другого экземпляра модуля своё поле и свой селектор.

1. Какую «Разметку полей» выбрать

Что хотите: чтобы поля и кнопка выглядели как остальной сайт.

Параметр: «Разметка полей» — Joomla (Bootstrap 5) для Cassiopeia и других шаблонов на Bootstrap, UIkit (YOOtheme) для YOOtheme Pro. На прочих шаблонах попробуйте оба и оставьте тот, что выглядит лучше; Без добавочных классов оставляет поля ровно такими, какими их рисует шаблон.

Как проверить: кнопка отправки принимает вид остальных кнопок сайта.

2. Форма выглядит не так, как ожидалось

Проверяйте по порядку:

  1. «Собственные стили»: Полный рисует рамки, обрамление и кнопку, Базовый — только отступы между полями, Нет отдаёт форму шаблону целиком.
  2. «Разметка полей»: чужой фреймворк добавляет классы, правил для которых у шаблона нет.
  3. Обновите страницу с Ctrl+Shift+R. Изменившийся файл стилей иначе остаётся в браузере прежним, и вы смотрите на старую версию.
  4. Очистите кэш шаблона, если он у вашего шаблона свой.

3. Тень вокруг формы

Что хотите: чтобы форма выделялась карточкой.

Параметр: ближайшие — «Рамка вокруг формы» и «Фон формы». Тени среди параметров нет намеренно: классом шаблона она делается одним полем, см. «Класс обёртки» и его card или uk-card.

Кусок:

ВАША-ФОРМА {
    box-shadow: 0 2px 14px rgba(0, 0, 0, .15);
    border-radius: 6px;
    padding: 20px;
}

Как проверить: тень появилась, поля не упираются в край. Строку padding уберите, если уже включены «Рамка вокруг формы» или «Фон формы»: отступ они дают сами.

4. Цвет кнопки при наведении

Что хотите: свой цвет под указателем мыши.

Параметр: «Вид кнопки» — Кнопка модуля, а её обычный цвет задаёт «Цвет акцента». При наведении модуль затемняет этот цвет сам, отдельного параметра на второй цвет нет.

Кусок:

ВАША-ФОРМА .mcx-submit:hover {
    background-color: #1f4f8f;
    filter: none;
}

Как проверить: наведите на кнопку. При виде «Как в шаблоне» наведение принадлежит шаблону, и этот кусок ничего не даст.

5. «Имя» и «E-mail» в одну строку на широком экране

Что хотите: два коротких поля рядом, остальные на всю ширину.

Параметр: нет. Модуль держит по полю в строке — так форма ведёт себя на телефоне.

Кусок:

@media (min-width: 640px) {
    ВАША-ФОРМА .mcx-form {
        display: grid;
        grid-template-columns: 1fr 1fr;
        column-gap: 16px;
    }

    ВАША-ФОРМА .mcx-form > * { grid-column: 1 / -1; }

    ВАША-ФОРМА .mcx-field-wrap:has(.mcx-field--name),
    ВАША-ФОРМА .mcx-field-wrap:has(.mcx-field--email) { grid-column: span 1; }
}

Как проверить: расширьте окно — «Имя» и «E-mail» встают в строку, поле сообщения и кнопка остаются во всю ширину. Сузьте обратно: снова по полю в строке.

6. Размер и цвет подписей

Что хотите: подписи потише или, наоборот, крупнее.

Параметр: нет. Шрифты и размеры текста по всему модулю принадлежат шаблону.

Кусок:

ВАША-ФОРМА .mcx-field .control-label {
    font-size: 15px;
    font-weight: 600;
    color: #555555;
}

Как проверить: меняются все подписи, включая текст согласия рядом с чекбоксом.

7. Форма на тёмном фоне

Что хотите: поставить форму в тёмную часть страницы.

Параметр: «Фон формы» принимает тёмный цвет, но текст и поля внутри остаются шаблонными.

Кусок:

ВАША-ФОРМА {
    color: #f0f0f0;
    --mcx-error: #ff9a90;
    --mcx-error-bg: #3a2020;
    --mcx-ok: #a5d6a7;
    --mcx-ok-bg: #1f3a24;
}

ВАША-ФОРМА .form-control,
ВАША-ФОРМА .form-select {
    background-color: #2a2c30;
    border-color: #555a61;
    color: #f0f0f0;
}

ВАША-ФОРМА .form-control::placeholder { color: #a6a6a6; }

Как проверить: отправьте пустую форму — отказ должен читаться и на тёмном, а не оказаться тёмно-красным по тёмно-серому.

8. Цвет сообщений об ошибке

Что хотите: свой красный или что-то мягче.

Параметр: нет: «Цвет акцента» отвечает за кнопку, фокус и чекбокс, а цвета ошибок к нему намеренно не привязаны.

Кусок:

ВАША-ФОРМА {
    --mcx-error: #b00020;
    --mcx-error-bg: #fdeaec;
}

Как проверить: отправьте форму с пустым полем «Имя». Новый цвет возьмут и текст под полем, и рамка самого поля.

9. Скрыть звёздочки обязательных полей

Что хотите: убрать * после подписей.

Параметр: нет. Звёздочку у каждого обязательного поля печатает Joomla.

Кусок:

ВАША-ФОРМА .control-label .star { display: none; }

Как проверить: звёздочек нет. Поля при этом остаются обязательными, и пустое по-прежнему отклоняется, — значит, скажите где-нибудь ещё, что заполнять обязательно.

10. «Ширина формы» не подействовала или сжала лишнее

Что хотите: форму уже, чем колонка, в которой она стоит.

Параметр: «Ширина формы». Он сужает весь модуль вместе с заголовком над формой, обращаясь к тому элементу, в который ваш шаблон заворачивает модуль.

Если шаблон положил в этот элемент несколько модулей, сузятся все. Верните «Ширину формы» в 0 и возьмите кусок — он сужает только эту форму:

ВАША-ФОРМА { max-width: 560px; }

Как проверить: соседние модули снова обычной ширины, а форма — той, что вы задали.

Если кусок не сработал

  • Проверьте, что ВАША-ФОРМА заменено селектором из подписи под полем «Свой CSS» — вместе с # и с верным номером.
  • Обновите страницу с Ctrl+Shift+R.
  • Правило шаблона может оказаться сильнее. Напишите селектор дважды подряд, без пробела между ними: #mcx-12#mcx-12 .mcx-submit { … } — приём некрасивый, но честный, и это по-прежнему не !important.
